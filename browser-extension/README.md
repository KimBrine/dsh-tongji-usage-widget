# Chrome 登录助手

这个扩展为 DSH 同济 AI 积分浮窗更新登录凭据。它只使用学校与 AI 平台正常的登录跳转，不保存学校密码，不填写密码或验证码。

## 一次性连接

1. 保持 DSH 中的同济 AI 积分浮窗运行。
2. 在 Chrome 扩展管理页加载当前 `browser-extension` 文件夹。安装扩展属于一次性步骤，请先查看 `manifest.json` 的权限。
3. 在浮窗的自动登录设置中生成 8 位配对码，点击 Chrome 工具栏中的“同济 AI 登录助手”，输入该码并连接。
4. 默认本机端口是 `17945`；若浮窗显示了其他端口，把扩展中的端口改为该值。
5. 点击“立即更新登录”验证一次。助手会创建一个后台登录标签，完成并经本机后端验证后自动关闭。此后登录临近到期时由插件自动请求更新。

学校已有登录状态有效时，通常不需要输入密码。学校要求重新认证时，浮窗会提示；在扩展里点击“继续学校登录”，然后在学校页面自行完成。助手不会绕过密码、验证码或浏览器警告。

## 数据与权限

- 只在 `https://agi.tongji.edu.cn/*` 注入脚本，只读取助手为当前更新任务创建的标签。普通浏览标签不会被读取。
- 网站令牌仅暂存在内存，通过 `http://127.0.0.1:<本机端口>` 发给同机插件；不进入 URL、DOM、日志或扩展存储，不发送给第三方。后端会向同济 AI 平台验证令牌后保存。
- Chrome 扩展存储只保存本机配对密钥与端口；会话存储只保存非敏感任务元数据（编号、助手标签、时间和进度），以便 Chrome 后台进程休眠后恢复。
- 不申请 `cookies`、`history`、`debugger` 或广泛的 `tabs` 权限，不读取 Cookie 数据库，不读取密码管理器。
- Chrome 打开且本机插件运行时，后台定时约每 30 秒检查更新任务，手动操作会立即检查。Chrome 关闭或插件未运行时不会取得新凭据。

扩展不能保证学校登录永不过期。配对密钥不是网站登录令牌，仅授权这个扩展向本机插件提交受验证的新凭据。
